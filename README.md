# Smart Attendance Monitoring System using MobileFaceNet

A face recognition-based attendance system built with MobileFaceNet (InsightFace),
designed to handle lighting and angle variations better than traditional Haar Cascade + LBPH.

## Features
- Real-time face detection and recognition
- Deep learning-based face embeddings (512-d vectors)
- Automatic attendance logging with timestamp
- Duplicate attendance prevention

## Tech Stack
- Python, OpenCV, InsightFace (MobileFaceNet), ONNX Runtime
